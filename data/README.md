# Датасет оттока клиентов

**Источник:** генератор `src/data/generate.py`, сид из `params.yaml`.
В боевом проекте здесь была бы выгрузка из биллинга.

**Владелец:** Yuliya Mikhailova

**Обновление:** не обновляется сам. Датасет пересоздаётся командой `make data`
и при тех же `seed` и `n_samples` получается тем же самым. Версия файла
хранится в DVC (`data/raw/churn.csv.dvc`), получить её можно через `dvc pull`.

**Объём:** 20 000 строк (`data.n_samples`), 12 колонок, одна строка — один клиент.

## Поля

| Поле | Тип | Единица | Диапазон | Комментарий |
|---|---|---|---|---|
| customer_id | str | — | `C0000000`… | идентификатор клиента, уникальный; в модель не идёт |
| tenure_months | int | месяцы | 1–72 | стаж клиента |
| monthly_charges | float | руб./мес | 15–180 | текущий тариф |
| total_charges | float | руб. | ≈ 14–13 600 | сумма списаний за всё время; есть пропуски |
| contract_type | category | — | `month-to-month`, `one_year`, `two_year` | тип контракта |
| internet_service | category | — | `fiber`, `dsl`, `none` | тип интернета; `none` — нет интернета |
| payment_method | category | — | `electronic_check`, `mailed_check`, `bank_transfer`, `credit_card` | способ оплаты |
| num_support_calls | int | звонки | ≥ 0 | число обращений в поддержку |
| has_tech_support | int (0/1) | — | 0, 1 | подключена ли техподдержка |
| avg_monthly_gb | float | ГБ/мес | 0.5–300 | средний трафик в месяц |
| is_senior | int (0/1) | — | 0, 1 | клиент пенсионного возраста |
| churn | int (0/1) | — | 0, 1 | **таргет**: 1 — клиент ушёл |

## Известные дефекты

- `total_charges` пустой примерно у 1 % строк (200 из 20 000). Пропуски
  разбросаны случайно по всем клиентам, а не только по новым, хотя комментарий
  в генераторе говорит про новых. `prepare.py` заполняет их как
  `monthly_charges * tenure_months`.
- `total_charges` не равен в точности `monthly_charges * tenure_months`:
  генератор умножает его на случайный множитель 0.92–1.05. Поэтому заполнение
  пропусков в `prepare.py` даёт оценку, а не точное значение.
- Классы несбалансированы: ушедших около 20 %. Из-за этого порог 0.5 даёт
  низкий recall (см. `reports/EXPERIMENTS.md`).
- `internet_service = none` — это категория «нет интернета», а не пропуск.
  При чтении из других инструментов её легко принять за `NaN`.
- Разный стиль значений в `contract_type`: `month-to-month` через дефис,
  `one_year` и `two_year` через подчёркивание.
- Данные синтетические: вероятность оттока задана логитом, линейным по
  признакам, поэтому на реальные данные результаты моделей не переносятся.
