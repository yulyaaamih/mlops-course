# Проблемы baseline_notebook.py

Список проблем, мешающих воспроизведению на другой машине:

1. захардкоженный путь до данных
2. нет валидации входного датасета
3. магические числа в определении RandomForestClassifier
4. print вместо логгера
5. нет разделения на ф-ции чтения и запуска модели
6. нет версионирования модели
7. не зафиксирован `random_state` (train_test_split, RandomForest), поэтому AUC меняется от запуска к запуску.
8. в семпле не зафиксированы версии библиотек
